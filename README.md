# Mon CV Pro — Portfolio Cinématographique Haute-Fidélité

Portfolio et CV interactif haute-fidélité de **Glad Jhinaldi Dellys MOUKOUIRI** — Ingénieur Biomédical & Spécialiste Systèmes de Biologie Médicale.

---

## Fonctionnalités

- **Texture de Bruit Analogique (Anti-Banding)** : Overlay SVG `<feTurbulence>` sans blocage de clics.
- **4 Directions Artistiques (Presets Directives)** :
  - `Preset A` : Architecte Minimal (Fond Neige, Corail & Encre)
  - `Preset B` : Nocturne Prestige (Fond Sombre, Or Brossé)
  - `Preset C` : Signal Brut (Fond Brut, Bleu Signal)
  - `Preset D` : Aura Digitale (Fond Sidéral, Violet Électrique)
- **Floating Capsule Navbar** : Navigation fluide avec sélecteur de thèmes et CTA direct.
- **Visualiseur de Compétences Dashboard** : Radar SVG computationnel vectoriel et jauges d'aptitudes réactives.
- **Timeline Vivante** : Présentation détaillée des déploiements majeurs (Banque Mondiale ISMEA, GIZ ENDEV Santé, Hôpital International ASFADAR, Ministère de la Santé).
- **Habilitations Spécialisées** : Microscopes LEICA Niveau 1, Certification HSST & Risques (ISO 45001 / ISO 31000), Audit Interne SMQ (ISO 9001:2015).

---

## Visualisation Locale

Ouvrez simplement `index.html` dans n'importe quel navigateur moderne, ou lancez un serveur local :

```bash
python3 -m http.server 8080
```
Puis accédez à `http://localhost:8080/index.html`.
